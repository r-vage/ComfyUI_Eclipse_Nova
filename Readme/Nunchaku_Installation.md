# Nunchaku setup

Diffusion-model loading and Nunchaku integration belong to
[Smart Model Loader Nova](https://github.com/r-vage/ComfyUI_SmartModelLoader_Nova).
Follow that repository’s current installation and model-loading documentation,
and the [ComfyUI-nunchaku project](https://github.com/nunchaku-tech/ComfyUI-nunchaku)
for its runtime requirements.

Eclipse Nova does not install Nunchaku or include model-loader, LoRA Stack or
PuLID nodes. Its prompt, image, routing and sampler-setting tools can be used
alongside a compatible loader through their documented inputs and outputs.

The older installation walkthrough here described a different loader release
and is no longer maintained in this repository.
